# 브라우저 화면 검증 결과

- 검증일: 2026-10-08
- 대상: Live Buddy 0.1.20, `test/auth-broadcast-regressions` 브랜치의 2ef7895 코드
- 환경: macOS, Vite 개발 서버, Codex 내장 브라우저
- 주소: `http://127.0.0.1:5173`
- 범위: 로그인 전 화면. 실제 서버 로그인·회원가입·방송은 수행하지 않았습니다.

이 범위에서 재현된 기능 오류는 없었습니다. Google 로그인·회원가입 버튼은 준비 중으로 비활성화되어 있었으며, 해당 기능의 완료를 의미하지 않습니다. 비밀번호 표시는 상태 전환을 확인했으며 보안 기능 전반을 감사한 것은 아닙니다.

## 재현 순서

1. `swproject`에서 `npm run dev -- --host 127.0.0.1` 실행.
2. 저장된 로그인 정보가 없는 브라우저에서 위 주소 열기.
3. 빈 상태에서 로그인 클릭 후 두 입력 안내 확인.
4. 테스트용 비밀번호를 입력하고 보기 버튼 전환 확인.
5. 회원가입 링크 클릭 후 테스트 이름·이메일과 서로 다른 비밀번호 입력.
6. 가입하기 클릭 후 비밀번호 불일치 안내 확인. 실제 계정은 생성하지 않음.
7. `/#/dashboard`로 직접 이동하여 `/#/login` 복귀 확인.
8. 새로고침 후 화면 및 오류 로그 확인.

## 다음 통합 검증에 필요한 조건

- 사용 가능한 개발 백엔드와 테스트 계정: 정상 로그인, 캐릭터 조회·수정, 로그인 이후 페이지 이동
- Electron 실행과 마이크 권한: 음성 입력, 방송 종료 후 장치·연결 정리
- OBS 테스트 환경: 캐릭터·오버레이 동기화

이번 결과는 브라우저 UI 확인이며 Electron 설치 파일, 실서버, 마이크, OBS 동작을 보장하지 않습니다. 테스트 계정이나 운영 계정의 비밀번호는 문서에 기록하지 않습니다.


## 로컬 샘플 환경 추가 확인 (2026-10-08)

대상: `npm run dev:demo`, `http://127.0.0.1:5174`, Codex 내장 브라우저.

- 고정 테스트 사용자로 로그인 후 대시보드 이동 확인
- 방송 미진행 안내, 캐릭터 0개 안내, 채팅 분석의 비활성 방송 안내 확인
- 방송 통계의 0회 기록 및 달력 표시 확인
- 통계 화면 새로고침 후 로그인 상태·페이지 유지 확인
- 계정 메뉴의 로그아웃 후 로그인 화면 복귀 확인
- 오류 로그 조회 시 수집된 error 없음

API 응답은 모두 로컬 샘플. 실제 서버의 사용자 인증·데이터 정확성·캐릭터 CRUD·방송 중 이동·마이크·OBS는 미검증. 샘플 HTTP 경계 테스트 1개 및 기존 테스트 9개 통과, 프론트 빌드·Electron 컴파일 통과, 린트 오류 0개와 기존 경고 7개 확인.
