## 💡 개발 시 주의사항

### 백엔드 요구사항

각 기능 개발 전에 백엔드에서 제공해야 할 API 엔드포인트:

**인증**
- POST /api/v1/auth/register/email
- POST /api/v1/auth/login/email
- POST /api/v1/oauth/google/callback

**캐릭터**
- POST /api/v1/characters
- GET /api/v1/characters
- PUT /api/v1/characters/{id}
- DELETE /api/v1/characters/{id}
- POST /api/v1/characters/{id}/presets

**채팅 분석**
- GET /api/v1/chat-analysis/sentiment
- GET /api/v1/chat-analysis/keywords
- GET /api/v1/chat-analysis/statistics

**게임 연동**
- GET /api/v1/game/live-data (Riot API 래핑)
- GET /api/v1/game/events

**기타**
- GET /api/v1/broadcast/statistics/{date}
- POST /api/v1/safety/banned-words
