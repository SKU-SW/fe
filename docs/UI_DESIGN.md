## 전체 개요

### 프로젝트 정보

**프로젝트명**: AI 스트리머 동료 시스템
**플랫폼**: Windows/Mac 데스크톱 Electron 애플리케이션
**테마**: 다크 테마 (어두운 전문적인 느낌)
**포인트 컬러**: 파란색 (#3B82F6)

### 설계 원칙

1. **스트리머 친화적**: 방송 중에도 쉽게 확인하고 제어 가능
2. **실시간 모니터링**: 핵심 수치는 크게, 부가 정보는 작게
3. **원클릭 제어**: 빠른 On/Off 기능 중심
4. **어두운 배경**: 장시간 방송 중에도 눈 피로 최소화

## 페이지별 설계

### 1. 로그인 / 회원가입 페이지

**위치**: `/login`, `/signup`

**구성요소**:
- 상단 로고 + 앱 제목
- 이메일 입력 필드
- 비밀번호 입력 필드
- 로그인/회원가입 버튼
- 소셜 로그인 (Google OAuth2)
- 계정 전환 링크 ("이미 계정이 있으신가요?" / "계정 만들기")

**레이아웃**: 중앙 정렬, 카드 형태 (max-width: 400px)

**색상**:
- 배경: 다크 슬레이트
- 카드: 슬레이트-800
- 버튼: 파란색 (활성), 슬레이트-700 (비활성)

---

### 2. 메인 대시보드

**위치**: `/dashboard`

**전체 레이아웃**: 3 섹션 구조

```
┌─────────────────────────────────────────┐
│  [⚙ Settings]  제목 및 설명        [빠른 제어]  │
├─────────────────────────────────────────┤
│                                         │
│  상태 카드 (4개) - 가로 배치           │
│                                         │
│  ┌──────────────────┐  ┌──────────┐   │
│  │ 좌측 영역        │  │ 우측    │   │
│  │ - 제어 패널     │  │ - 채팅  │   │
│  │ - 설정 패널     │  │ 모니터  │   │
│  │                 │  │         │   │
│  └──────────────────┘  └──────────┘   │
│                                         │
│  AI 활동 로그 (전체 너비)              │
│                                         │
└─────────────────────────────────────────┘
```

**⚙ 설정 아이콘**: 사이드바 상단, 세부 설정 패널 토글

#### 2.1 상태 카드 (Status Cards)

**구성**: 4개 카드, 가로 배치

**각 카드의 상태**:

1. **AI 상태**
   - 타이틀: "AI 상태"
   - 값: "활성화" / "일시정지" / "오류"
   - 아이콘: 봇 아이콘
   - 색상: 활성(초록), 일시정지(노랑), 오류(빨강)
   - 배지: 게임/카테고리 태그 (예: "LOL")

2. **현재 시청자 수**
   - 타이틀: "현재 시청자 수"
   - 값: 숫자 (예: "1,234")
   - 아이콘: 사람 아이콘
   - 부제: "+12% vs 어제"

3. **채팅 속도**
   - 타이틀: "채팅 속도"
   - 값: "42개/분"
   - 아이콘: 메시지 아이콘
   - 부제: "평균: 35개/분"

4. **실시간 감정 비율**
   - 타이틀: "감정 비율"
   - 값: "긍정 73%"
   - 아이콘: 막대 그래프
   - 색상: 긍정(초록), 중립(회색), 부정(빨강)

**스타일**:
- 배경: 투명 + 색상별 경계선
- 크기: 각각 약 250px × 120px

#### 2.2 우측 상단 빠른 제어 영역

**구성요소**:

1. **AI 일시정지 토글**
   - 기본: "⏸ 일시정지" (회색)
   - 활성: "▶ 재개" (빨강)
   - 색상 변화: 클릭 시 토글

2. **감정 빠른 전환 버튼** (3개)
   - "😄 밝게" - 밝은 톤
   - "😐 진지하게" - 중립 톤
   - "😆 재미있게" - 재미있는 톤
   - 선택된 항목: 파란색 하이라이트

**배치**: 우측 상단 고정, 가로 배치

**스타일**:
- 버튼 간격: 8px
- 버튼 높이: 40px
- 폰트: 14px, Semibold

#### 2.3 좌측 영역

**섹션 1: 제어 패널 (Control Panel)**

- 제목: "AI 반응 전략"
- 옵션 선택:
  - 🤖 자동 (자동으로 여론에 따라 반응)
  - 👍 응원 (항상 응원 톤)
  - 😐 일반 (중립 톤)
  - 👎 비판 (비판적 톤)
- 선택된 옵션: 파란색 배경
- 각 옵션 설명 텍스트 포함

**섹션 2: 설정 패널 (Settings Panel) - 메인 화면**

⚠️ **[메인 화면에서 제거] → 세부 설정 패널로 이동**

기존 슬라이더는 모두 삭제되고, 우측 사이드 슬라이드 패널에서 관리

#### 2.4 우측 영역

**채팅 모니터 (Chat Monitor)**

- 제목: "실시간 채팅"
- 채팅 목록: 최근 10개 표시
- 각 채팅 항목:
  - 사용자명 (12px, 회색)
  - 메시지 (14px, 흰색)
  - 여론 아이콘 (👍/➖/👎 또는 색상 배지)
  - 시간 (10px, 초소 텍스트)
- 스크롤 가능
- 높이: 자동 확장

**스타일**:
- 배경: 슬레이트-800
- 경계선: 슬레이트-700
- 최대 너비: 약 350px

#### 2.5 하단 영역

**AI 활동 로그 (AI Activity Log)**

- 전체 너비
- 타이틀: "AI 활동 로그"
- 타임라인 형식 또는 테이블 형식
- 컬럼: 시간 | 이벤트 | 상세
- 예시:
  ```
  10:32  | 채팅 반응  | "재미있네요!"를 긍정으로 분류
  10:30  | 감정 변화  | 감정 전략: 자동 → 응원 (여론 변화)
  10:28  | 게임 연동  | LOL 킬 감지 → 축하 반응 발생
  ```

### 3. 왼쪽 사이드 슬라이드 설정 패널

**트리거**: 사이드바 상단 ⚙ 아이콘 클릭

**위치**: 사이드바 우측, 고정된 것처럼 보임

**크기**: 약 280px 너비, 전체 높이

**구성**:

1. **헤더**
   - 제목: "AI 세부 설정"
   - 닫기 버튼 (X 아이콘, 우측 상단)

2. **슬라이더 항목들**

   a) **채팅 반응 민감도**
   - 레이블: "채팅 반응 민감도"
   - 현재값: "50%" (우측 상단, 파란색)
   - 슬라이더: 0 ~ 100
   - 하단 라벨: "낮음" / "높음"

   b) **선제 반응 빈도**
   - 레이블: "선제 반응 빈도"
   - 현재값: "30초" (우측 상단, 파란색)
   - 슬라이더: 10 ~ 120초
   - 하단 라벨: "10초" / "120초"

   c) **음성 출력 속도**
   - 레이블: "음성 출력 속도"
   - 현재값: "1.0x" (우측 상단, 파란색)
   - 슬라이더: 0.5 ~ 2.0x
   - 하단 라벨: "0.5x" / "2.0x"

   d) **음성 음량**
   - 레이블: "음성 음량"
   - 현재값: "70%" (우측 상단, 파란색)
   - 슬라이더: 0 ~ 100%
   - 하단 라벨: "0%" / "100%"

**스타일**:
- 배경: 슬레이트-800 (메인보다 약간 밝음)
- 경계선: 우측에만 (좌→우 구분 효과)
- 그림자: 우측에 섀도우
- 오버레이: 패널 뒤에 반투명 검은색 배경 (클릭 시 닫힘)
- 패널 외부 클릭 시 자동 닫힘

## 컴포넌트 설계

### 1. 버튼 컴포넌트

**타입별 스타일**:

#### Primary Button (파란색)
```
배경: #3B82F6
텍스트: 흰색
상태:
  - 기본: #3B82F6
  - Hover: #2563EB (더 어두움)
  - Active: #1D4ED8 (가장 어두움)
  - Disabled: #64748B (회색)
```

#### Secondary Button (회색)
```
배경: #475569
텍스트: #E2E8F0
상태:
  - 기본: #475569
  - Hover: #334155
  - Active: #1E293B
```

#### Danger Button (빨강)
```
배경: #EF4444
텍스트: 흰색
상태:
  - 기본: #EF4444
  - Hover: #DC2626
  - Active: #991B1B
```

**크기**:
- Small: 32px 높이, 12px 패딩
- Medium: 40px 높이, 16px 패딩 (기본)
- Large: 48px 높이, 20px 패딩

### 2. 입력 필드 (Input)

**스타일**:
```
배경: #1E293B (슬레이트-800)
텍스트: #F1F5F9 (흰색)
경계선: #334155 (슬레이트-700)
높이: 40px
패딩: 12px 16px
```

**상태**:
- Focus: 경계선 파란색 (#3B82F6), 박스 섀도우
- Error: 경계선 빨강 (#EF4444)
- Disabled: 배경 회색, 텍스트 회색

### 3. 슬라이더 컴포넌트

**구성**:
```
├─ 레이블 (좌) + 현재값 (우, 파란색)
├─ 슬라이더 바
│  ├─ 배경: #334155
│  ├─ 채워진 부분: #3B82F6
│  └─ 핸들: 흰색 동그라미 (hover 시 확대)
└─ 최소/최대값 라벨
```

**인터랙션**:
- 드래그 가능
- Hover: 핸들 크기 증가
- 실시간 값 표시

### 4. 상태 카드 (Status Card)

**구성**:

**상태별 색상**:

## 인터랙션 & 애니메이션

### 1. 토글 애니메이션

**AI 일시정지 버튼**:
```
클릭 전: "⏸ 일시정지" (회색)
↓ Click
클릭 후: "▶ 재개" (빨강) - 즉시 변색
↓ Click
원래대로: "⏸ 일시정지" (회색)
```

**시간**: 즉시 변경 (트랜지션 0.2초)

### 2. 감정 버튼 선택

**기본 상태**:
```
[ 😄 밝게 ]  [ 😐 진지하게 ]  [ 😆 재미있게 ]
회색           회색             회색
```

**선택 후**:
```
[ 😄 밝게 ]  [ 😐 진지하게 ]  [ 😆 재미있게 ]
파란색        회색              회색
```

**트랜지션**: 0.15초

### 3. 사이드 패널 슬라이드

**열림**:
1. 패널 뒤에 검은색 오버레이 나타남 (0.2초)
2. 패널이 우측에서 좌측으로 슬라이드인 (0.3초)

**닫힘**:
1. 패널이 우측으로 슬라이드아웃 (0.3초)
2. 오버레이 사라짐 (0.2초)

### 4. 호버 효과

**버튼**:
```
배경색 약간 어두워짐 (0.1초)
```

**카드**:
```
경계선 색상 변경 (0.1초)
박스 섀도우 추가 (0.1초)
```

### 5. 펄스 애니메이션

**활성 상태 표시**:
```
작은 동그라미 (w-2 h-2)
초록색
반복적으로 밝아졌다 어두워짐 (1초 사이클)
```

## 주의사항

1. **다크 테마 유지**: 밝은 배경은 사용 금지
2. **파란색 포인트**: 모든 활성 상태, 선택, 강조는 파란색 사용
3. **크기 계층**: 핵심 수치 (28px) > 제목 (18px) > 본문 (14px)
4. **간격 일관성**: 모든 컴포넌트 간 최소 8px 이상 간격
5. **애니메이션 부드러움**: 모든 트랜지션 0.15~0.3초 사이
