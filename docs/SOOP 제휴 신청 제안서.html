1. 프로젝트명

AI Streamer Partner

AI 캐릭터가 스트리머의 방송 진행을 보조하고, 시청자 채팅 흐름을 함께 읽으며 반응하는 방송 관리 데스크톱 앱입니다.

2. 팀명

SKU-SW 프로젝트팀

소프트웨어 개발 학습 및 프로젝트 목적으로 AI 캐릭터 방송 보조 시스템을 개발하는 팀입니다. 회사 법인 서비스가 아닌 프로젝트 팀 단위로 신청합니다.

3. 서비스 목적

AI Streamer Partner는 SOOP 스트리머가 외부 송출 환경에서도 AI 캐릭터와 함께 방송을 진행할 수 있도록 돕는 데스크톱 애플리케이션입니다. 스트리머의 음성 입력과 시청자 채팅을 바탕으로 AI 캐릭터가 대화하거나 반응하고, 방송 중 필요한 채팅 흐름과 통계를 대시보드에서 확인할 수 있도록 합니다.

스트리머 친화적 제어
방송 중 빠른 토글, Push-to-Talk, AI 응답 제어를 제공합니다.
AI 캐릭터 방송 보조
캐릭터 페르소나, 말투, 음성, 외형을 설정해 방송 컨셉에 맞게 활용합니다.
실시간 채팅 흐름 확인
AI 캐릭터, 스트리머, 시청자 채팅을 하나의 대화창에서 시간순으로 표시합니다.
채팅 분석 확장
향후 채팅 속도, 여론, 키워드, 안전 필터링과 연결합니다.

4. SOOP API 사용 목적

SOOP 공식 OAuth 및 Chat SDK를 사용하여 스트리머 본인의 SOOP 계정을 연동하고, 본인 방송의 실시간 채팅을 수집·표시하는 것이 핵심 목적입니다.

사용 항목활용 목적
SOOP OAuth스트리머 본인 계정 인증 및 본인 방송 채팅 접근 권한 확인
Chat SDK본인 방송의 실시간 채팅 메시지 수신
채팅 메타데이터닉네임, 메시지 타입, 수신 시각 등을 대시보드와 분석 기능에 활용
방송 상태 데이터시청자 수, 채팅 속도 등 방송 지표 표시 기능으로 확장

연동 흐름

1. 스트리머가 앱에서 SOOP 계정 연동 선택 2. SOOP OAuth 인증 후 백엔드가 토큰을 안전하게 저장 3. 방송 시작 시 SOOP Chat SDK로 본인 방송 채팅 연결 4. 수신한 채팅을 대시보드 채팅창에 실시간 표시 5. 필요한 범위의 채팅 로그를 방송 대화 기록으로 저장

6. 개인정보/채팅 데이터 처리 방식

  • 수집 범위 제한: SOOP 연동 스트리머 본인의 방송 채팅만 수집합니다.
  • 사용 목적 제한: 수집된 채팅은 대시보드 표시, AI 캐릭터 반응, 방송 대화 로그, 채팅 분석 기능에 한해 사용합니다.
  • 토큰 보관: SOOP Client Secret과 refresh token은 프론트/Electron에 저장하지 않고 백엔드 서버에서 암호화하여 관리합니다.
  • 화면 데이터 최소화: 프론트 채팅창은 최신 메시지만 임시 보관하며, 대시보드 재진입 시 기존 화면 채팅을 비웁니다.
  • 저장 데이터: 방송 식별자, 메시지 내용, 발화 주체, 수신 시각, 필요한 경우 시청자 닉네임 및 플랫폼 정보를 저장합니다.
  • 보안 처리: 서비스 API는 JWT 기반 인증을 사용하며, 401 발생 시 토큰 갱신 후 재시도하는 구조를 사용합니다.
  • 관리 기능: 스트리머가 방송 종료 또는 연동 해제를 수행할 수 있도록 하고, 불필요한 데이터 저장을 최소화합니다.

본 프로젝트는 SOOP 공식 API/SDK 정책을 준수하여, 스트리머 본인이 인증한 방송 채팅에 한정해 기능을 제공합니다.

7. 기대 효과

  • 스트리머가 외부 송출 환경에서도 SOOP 채팅을 AI 캐릭터와 자연스럽게 연동할 수 있습니다.
  • 시청자 채팅을 AI 반응과 방송 대화 흐름에 반영하여 방송 상호작용성을 높일 수 있습니다.
  • 채팅 속도, 여론, 키워드 분석 등 향후 방송 분석 기능의 정확도를 개선할 수 있습니다.
  • SOOP 생태계 안에서 AI 기반 방송 보조 도구 활용 사례를 만들 수 있습니다.
