# Live Buddy v0.1.0

AI 캐릭터 방송 관리 데스크톱 앱 첫 배포본입니다.

## 다운로드

| OS | 파일 | 비고 |
|----|------|------|
| macOS (Apple Silicon) | `Live-Buddy-0.1.0-arm64.dmg` | M1 이상. Intel Mac 미지원 |
| Windows (x64) | `Live-Buddy-Setup-0.1.0.exe` | 64-bit |

> STT(음성 인식) 모델이 앱에 동봉되어 있어 별도 Python·모델 설치가 필요 없습니다.

## 설치 방법

### macOS
1. `.dmg` 를 열고 **Live Buddy** 를 응용 프로그램 폴더로 드래그.
2. 첫 실행 시 *"손상되었기 때문에 열 수 없습니다"* 가 뜨면 — 코드 서명이 없는 앱이라 그렇습니다. 둘 중 하나로 해제하세요.
   - **방법 A (간단):** 앱을 **우클릭 → 열기 → 열기**.
   - **방법 B (터미널):**
     ```bash
     xattr -dr com.apple.quarantine "/Applications/Live Buddy.app"
     ```
3. 첫 실행 시 마이크 접근 권한을 허용해 주세요 (음성 인식에 필요).

### Windows
1. `.exe` 실행 → 설치.
2. *"Windows의 PC 보호"* (SmartScreen) 경고가 뜨면 — 서명되지 않은 앱이라 그렇습니다.
   **추가 정보 → 실행** 을 누르세요.

## 사전 준비물
- **인터넷 연결** — 백엔드 서버(`dev.sku-sw.cloud`)와 통신합니다.
- **OBS Studio** — 방송 송출/오버레이 기능은 OBS가 설치되어 있어야 동작합니다. (앱에 포함되어 있지 않음)

## 알려진 제약
- 코드 서명/공증이 없어 위와 같은 1회 보안 경고 우회가 필요합니다.
- macOS는 Apple Silicon(arm64)만 지원합니다. (Intel Mac 미지원)
- STT는 한국어 기준으로 최적화되어 있습니다.

## 문제가 생기면
- 앱이 열리지 않음 → 위 "설치 방법"의 보안 경고 우회 단계를 확인하세요.
- 로그인/데이터가 안 불러와짐 → 인터넷 연결 및 백엔드 서버 상태를 확인하세요.
- 음성 인식이 안 됨 → 마이크 권한 허용 여부를 확인하세요.
