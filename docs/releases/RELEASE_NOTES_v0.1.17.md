# Live Buddy v0.1.17

## ✨ 변경 사항

- **방송 통계 상세 개선**
  - `catchPhrases` 응답 구조를 문자열 목록이 아닌 객체 목록(`content`, `subject`, `situationAnalysis`) 기준으로 반영했습니다.
  - 방송 상세 모달에서 유행어의 주체와 상황 설명을 함께 표시하도록 개선했습니다.
  - 진행 중 / 비정상 종료 방송에 대한 상태 안내 문구를 추가했습니다.

- **방송 캘린더 가독성 개선**
  - 방송 상태를 `정상 종료`, `비정상 종료`, `방송 중 (LIVE)`로 더 명확하게 표현했습니다.
  - 셀 배경/상태 칩/상태 점 색상을 상태 우선순위에 따라 다르게 표시하도록 개선했습니다.

- **캐릭터 3D(VRM) 복원 보정**
  - VRM preset 매칭 시 썸네일 URL 기준 복원을 추가해 수정 페이지에서 기존 선택값이 더 정확히 복원되도록 보완했습니다.
  - 저장 시 preset 식별자 처리도 보정해 일부 저장 실패 케이스를 줄였습니다.

- **문서 반영**
  - 방송 통계 API 명세를 현재 Swagger 기준(`/api/v1/broadcast/stats/month`, `/api/v1/broadcast/stats/day`)으로 정리했습니다.
  - `catchPhrases` 객체 구조 변경 내용을 stats 문서에 반영했습니다.

- **치지직 연동 완료 페이지 안내 개선**
  - 브라우저 보안 정책으로 자동 닫힘이 안 되는 경우를 고려한 안내 문구로 수정했습니다.
