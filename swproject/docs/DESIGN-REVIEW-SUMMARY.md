## 💡 설계 철학

### 1. **일관성 (Consistency)**
- 다크 테마로 전체 통일
- 색상 팔레트 명확히 정의
- 컴포넌트 재사용 극대화

### 2. **접근성 (Accessibility)**
- WCAG 2.1 AA 준수
- 색상만으로 정보 전달 금지
- 키보드 네비게이션 완벽 지원

### 3. **반응형 (Responsive)**
- 모바일/태블릿/데스크톱 대응
- Tailwind 그리드 시스템 활용
- 터치 친화적 UI

### 4. **성능 (Performance)**
- 컴포넌트 분리로 재사용성 ↑
- 불필요한 리렌더링 최소화
- 상태 관리 최적화 (Zustand)
