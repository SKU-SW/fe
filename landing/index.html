이 앱은 코드 서명이 없어 처음 실행할 때 1회 보안 경고가 나타날 수 있습니다. 아래 방법으로 해제하세요.

macOS — "손상되었기 때문에 열 수 없습니다"

  • 앱을 우클릭 → 열기 → 열기, 또는
  • 터미널에서 xattr -dr com.apple.quarantine "/Applications/Live Buddy.app"
  • 첫 실행 시 마이크 접근 권한을 허용해 주세요 (음성 인식에 필요).

Windows — "Windows의 PC 보호" (SmartScreen)

  • 추가 정보 → 실행 을 누르세요.

공통

  • 백엔드 서버와 통신하므로 인터넷 연결이 필요합니다.
  • 방송 송출·오버레이 기능은 OBS Studio가 설치되어 있어야 동작합니다.
